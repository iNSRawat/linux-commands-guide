# Arch Linux System Services (systemd)

Manage system services and boot processes using `systemd` on Arch Linux.

## Service Management

`systemd` is the default init system and service manager on Arch Linux. Commands are executed using the `systemctl` utility.

### Basic Commands
```bash
sudo systemctl start service     # Start a service immediately
sudo systemctl stop service      # Stop a service immediately
sudo systemctl restart service   # Restart a service
sudo systemctl reload service    # Reload service configuration files without stopping
sudo systemctl status service    # View the current status and recent logs of a service
```

### Enable/Disable Services
```bash
sudo systemctl enable service        # Configure service to auto-start on boot
sudo systemctl disable service       # Disable auto-start on boot
sudo systemctl enable --now service  # Enable service and start it immediately (Recommended shortcut)
sudo systemctl disable --now service # Disable service and stop it immediately
sudo systemctl is-active service     # Check if the service is running (returns active/inactive)
sudo systemctl is-enabled service    # Check if the service is set to start on boot
```

### Common Arch Linux Services
```bash
sudo systemctl status NetworkManager # Network connection manager daemon
sudo systemctl status bluetooth      # Bluetooth connectivity service
sudo systemctl status ufw            # Uncomplicated Firewall daemon
sudo systemctl status sshd           # OpenSSH server daemon
```

### Listing Units
```bash
systemctl list-units                 # List active loaded services/units
systemctl list-units --all           # List all loaded units (active and inactive)
systemctl list-unit-files            # List all installed service files and their enabled states
systemctl list-dependencies service  # Show dependencies of a specific service
```

### Power Management Control
```bash
sudo systemctl reboot                # Reboot the system
sudo systemctl poweroff              # Shutdown the system
sudo systemctl suspend               # Suspend the system (sleep to RAM)
sudo systemctl hibernate             # Hibernate the system (sleep to disk)
```

## System Logs (journalctl)

Arch Linux uses `journalctl` to query and view logs generated by `systemd-journald`.

### Querying Logs
```bash
journalctl                           # View all logs starting from oldest (opens in less)
journalctl -f                        # Follow new logs in real-time (like tail -f)
journalctl -u service                # View logs for a specific service (e.g. journalctl -u bluetooth)
journalctl -p err                    # Show error logs (priority levels: emerg, alert, crit, err, warning, notice, info, debug)
journalctl -xe                       # Show recent logs with extended explanation of errors
journalctl --since "1 hour ago"      # Show logs from the last hour
journalctl --since "2026-06-01"      # Show logs since a specific date
journalctl -b                        # Show logs from the current boot only
journalctl -b -1                     # Show logs from the previous boot
```

## Container Daemon Management

Manage your container runtimes on Arch Linux.

### Docker Daemon
```bash
sudo pacman -S docker docker-compose  # Install Docker and compose tool
sudo systemctl start docker           # Start Docker daemon
sudo systemctl enable docker          # Start Docker automatically on boot
sudo usermod -aG docker $USER         # Add current user to Docker group (relaxes sudo requirement; restart terminal to apply)
```

### Podman Daemon
```bash
sudo pacman -S podman                # Install Podman (daemonless alternative to Docker)
```

## Bootloader Configuration & Management

Arch Linux installation requires manual bootloader setup. The most common options are **GRUB** and **systemd-boot**.

### GRUB (Grand Unified Bootloader)
If you chose GRUB, configure and regenerate the boot profile with:
```bash
sudo grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB
sudo grub-mkconfig -o /boot/grub/grub.cfg  # Regenerate GRUB configuration file
```

### systemd-boot
A modern, simple UEFI boot manager pre-installed with `systemd`:
```bash
sudo bootctl install                 # Install systemd-boot in the current ESP (/boot or /efi)
sudo bootctl update                  # Update systemd-boot binary when systemd upgrades
```

Configuration files for systemd-boot are located in `/boot/loader/loader.conf` and entries are in `/boot/loader/entries/`:
```ini
# Example entry: /boot/loader/entries/arch.conf
title   Arch Linux
linux   /vmlinuz-linux
initrd  /intel-ucode.img
initrd  /initramfs-linux.img
options root=UUID=your-uuid-here rw
```
