# Fedora System Services (systemd)

Manage system services using systemd on Fedora.

## Service Management

### Basic Commands
```bash
sudo systemctl start service     # Start service
sudo systemctl stop service      # Stop service
sudo systemctl restart service   # Restart service
sudo systemctl reload service    # Reload configuration
sudo systemctl status service    # Check status
```

### Enable/Disable Services
```bash
sudo systemctl enable service    # Auto-start on boot
sudo systemctl disable service   # Disable auto-start
sudo systemctl is-enabled service # Check if enabled
```

### Common Services
```bash
sudo systemctl status firewalld
sudo systemctl status sshd
sudo systemctl status httpd
sudo systemctl status mariadb
```

### System State
```bash
systemctl list-units             # List active units
systemctl list-units --all       # All units
systemctl list-unit-files        # All unit files
systemctl list-dependencies      # Show dependencies
```

### System Control
```bash
sudo systemctl reboot            # Reboot system
sudo systemctl poweroff          # Power off
sudo systemctl suspend           # Suspend
sudo systemctl hibernate         # Hibernate
```

## System Logs (journalctl)

Fedora uses `journalctl` to query and view logs generated by `systemd-journald`.

* `journalctl` - View all logs.
* `journalctl -f` - Follow logs in real-time (like `tail -f`).
* `journalctl -u <service>` - View logs for a specific service.
* `journalctl -p err` - Show error logs only.
* `journalctl -xe` - Show recent system logs with explanation.
* `journalctl --since "1 hour ago"` - Show logs from the last hour.

## Container Daemon Management

If you use Docker or Podman (default in Fedora) for containerization, use systemd to manage their engines.

* `sudo systemctl start docker` - Start Docker daemon.
* `sudo systemctl enable docker` - Configure Docker to start automatically on boot.
* `sudo usermod -aG docker $USER` - Add current user to Docker group (allows running without sudo).
* `sudo systemctl restart docker` - Restart Docker engine after config changes.
